To use this without installing any extensions:

Step 1: Make sure your Bookmarks Bar is visible in Chrome (press Ctrl + Shift + B).
Step 2: Drag this blue button up onto your Chrome Bookmarks Bar:

(Or right-click your bookmarks bar → "Add page" → Name: Auto-Reply → URL: paste the code below).
